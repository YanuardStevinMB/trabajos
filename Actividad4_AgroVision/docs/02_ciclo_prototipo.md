# Ciclo de vida aplicado al prototipo
1. **Concepto:** AgroVision como apoyo visual preventivo.
2. **Recolección de requisitos:** actores, RF, RNF y aceptación.
3. **Diseño rápido:** cultivo -> imagen -> análisis -> resultado -> historial.
4. **Construcción:** FastAPI + SQLite + Pillow + HTML/CSS/JS.
5. **Evaluación:** pruebas unitarias, integración y validaciones.
6. **Refinamiento:** mensajes, estadísticas, historial y corrección visual.
7. **Entrega:** código, instalación, Docker, pruebas y documentación.
